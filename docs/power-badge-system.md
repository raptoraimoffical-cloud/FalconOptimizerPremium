# Power Badge System

Updated 2026-03-20T03:06:34.561Z.

Badges are assigned by policy: eligibility, risk, and scope.

## Core rules
- Main UI entries must be documented, GUID-mapped powercfg items with supported apply/verify paths.
- Unsupported or unresolved entries get EXPERIMENTAL/UNDOCUMENTED and never remain in main.
- SYSTEM_WIDE is default for power policies; app-targeted badges are only for Speed Core catalog entries.
- HIGH_POWER_USE / POWER_SAVING_DISABLED / THERMAL_RISK are added when titles indicate aggressive performance behavior.
